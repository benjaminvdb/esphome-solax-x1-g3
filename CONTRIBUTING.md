# 🤝 Contributing

Thanks for helping out. A note that a step confused you is as useful as a pull request.

If you have a question or something doesn't work, open an
[issue](https://github.com/benjaminvdb/esphome-solax-x1-boost/issues/new/choose). The form
asks for your inverter model, serial number prefix, firmware version, RS485 module and a
log, which is what I need to help.

If it works on an inverter that isn't listed as tested yet, an issue with the model and
firmware version is very welcome, so I can add it to the README.

For changes to the configuration, please test them on a real inverter, run Validate in
ESPHome Builder (or `esphome config solax-x1.yaml`), and say in the pull request what you
tested.

The wiring diagram is generated by `diagrams/wiring.py`. Edit the script, run
`python diagrams/wiring.py`, and commit the script together with `images/wiring.svg`.

When writing documentation, keep sentences short, explain a technical word the first time
it appears (or add it to `docs/glossary.md`), and after each step say what the reader
should see when it worked.
